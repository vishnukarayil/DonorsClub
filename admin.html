Entries waiting for review

Suspicious entries are flagged from the Donors tab (open a donor's donations), or automatically when a repeat donor submits a different blood group. Flagged entries still count towards the tier until you delete them.

Deleted entries

Deleted entries no longer count towards any tier and are hidden from the Donors tab. You can restore them, or remove them from the database for good.

Donor cards

Each card carries a unique 6-character code and a QR. A donor types the code on the donation form; it can be used once. Generate a batch, print it, then press Activate when the cards are in your hands. Cards that are not activated cannot be used.

Tier names

Silver is what a donor gets on their first donation; each repeat donation moves them up one rung. You can rename and recolour the rungs, but not add or remove them.

Membership benefits

Each benefit unlocks at the tier you choose and stays unlocked for higher tiers. Donors see locked benefits greyed out. Turn a benefit off to hide it everywhere.
